Glossary

This chapter maps ZBrush terms to their SculptForge equivalents, so you can find a familiar tool quickly, and explains the terms that only SculptForge uses. "Not yet" means SculptForge doesn't have it today; see the roadmap for what is planned.

ZBrush terms in SculptForge#

ZBrushSculptForge
AlphaAlpha: built-in round, square and noise, or any grayscale image. Left shelf, Alpha palette. See Sculpting
Auto GroupsTool > Polygroups > By pieces (polygroup_by_connectivity)
BPR renderNot yet as a renderer. Headless renders and turntables with sculptforge --render (Scripting)
Brush pop-up (B)Brush picker, B, then type letters (B S T = Standard)
Clip brushesNot yet. The Trim brush shaves to a plane
Curve brushes, IMM, ZModeler, ZSpheresNot yet
Decimation MasterTool > Geometry > Decimate (decimate). See Geometry
Del HiddenTool > Visibility > Delete hidden (delete_hidden)
Divide (Ctrl+D)Tool > Geometry > Subdivide, Ctrl+D
Document, 2.5D canvas, pixolsNot planned: SculptForge is a 3D sculpting app only
Draw SizeDraw Size (top shelf, S, [ / ])
DynaMeshVoxel Remesh (Tool > Remesh, remesh). See Geometry
Focal ShiftNo slider for the built-in brushes. Custom brushes have Hardness and Tip sharpness in their recipe
Ghost, TranspNot yet. Inactive SubTools are drawn slightly dimmed
GoZGoZ: .GoZ import and export and the GoZ bridge (File > ZBrush (GoZ)). See Exporting
Group MaskedTool > Polygroups > From mask (polygroup_from_mask)
Group VisibleTool > Polygroups > Merge visible (polygroup_merge_visible)
Groups By NormalsTool > Polygroups > By normals with an angle (polygroup_auto_by_normals)
Layers (sculpt layers)Tool > Layers: sculpt layers with weights, exported as blend shapes. See Layers
LazyMouseLazyMouse stroke type (Stroke palette)
LightBoxLightBox, , (comma)
Live BooleanNot yet
Local symmetry, radial symmetryNot yet. Symmetry is X, Y and Z across the world axes
Mask by CavityTool > Masking > By cavity (mask_by_cavity)
Masking (Ctrl)Hold Ctrl to paint the mask, Ctrl+Alt to erase. See Masking
Mask Lasso, Select LassoNot yet. Rectangle hide works: Ctrl+Shift+drag
MatCapMaterial: Studio plus six MatCaps (M). Custom MatCap images not yet. See Polypaint
Morph targetA sculpt layer; exported as glTF morph targets and FBX/USD blend shapes
Mrgb, M (material channel)Not yet: there is no per-vertex material channel
Polyframe (PolyF, Shift+F)PolyF on the right shelf, W or Shift+F
PolygroupsPolygroups: same idea, same Ctrl+Shift gestures. See Polygroups and visibility
PolypaintPolypaint: Paint brush (P), Rgb, fills, cavity paint. See Polypaint
Projection MasterNot yet. Generate > Stamp projects an image onto the model from the view
QuickSaveQuickSave in the title strip; the last 10 are kept. See Projects
RgbRgb on the top shelf (paint while sculpting)
Rgb Intensity, Z IntensityStrength (top shelf, I)
Sculptris Pro, dynamic topologyNot yet
SDiv, D / Shift+D (subdivision levels)Not yet: Subdivide is a single, destructive step
SoloSolo on the right shelf or in Tool > SubTool
SpotlightNot yet
Store ConfigStore Config, Ctrl+Shift+I (Preferences > Config)
Stroke (Dots, DragRect, Spray)Stroke types Dots, DragRect, Spray, LazyMouse
SubToolSubTool: same idea, Alt+click to select. See SubTools
Texture paletteNot yet: there is no texture painting or texture slot
Transpose, Gizmo 3DNot yet. Use the Move brush, or move the camera with the right-shelf buttons
UV MasterNot yet. UVs that come in with a GoZ model are kept (and saved in projects)
Zadd / ZsubZadd / Zsub on the top shelf; Alt flips for one stroke
ZPluginNo in-app plugin system yet. Automate with the Python module, sculptforge-cli and MCP (Scripting)
ZRemesherNot yet (quad retopology is on the roadmap)
ZScriptScript commands: the console (backtick key), script files, sculptforge-cli. See Scripting
ZTL, ZPR filesNot supported. Use GoZ, OBJ, FBX or GLB to bring models over; save work as .sfproj

SculptForge terms#

TermMeaning
Brush LabThe AI brush creator: describe a brush in words and it builds a recipe you can tweak. Opens from AI Brush. See Brush Lab
Brush codeOne line of text (sfbrush1:...) that holds a whole brush, for sharing in chat or a forum. Paste with Ctrl+V
Brush libraryYour saved custom brushes, loaded at every start
Brush recipeThe data that defines a custom brush (direction, depth, plane, pinch, pattern and so on): values, never code
.sfbrushA file holding one brush recipe
.sfprojA SculptForge project file: the whole scene. See Projects
Command paletteF3: search every command, brush and setting by name and run it
Community galleryShared CC0 brushes you can install in one click (Community brushes)
ConsoleThe script console (backtick key): every action appears as a script line
Ctrl helpHold Ctrl and point at a control to see what it does, its shortcut and its command
Gaussian splatA 3D capture made of soft coloured blobs (from phone scanning apps). Load one as a reference, convert it to a mesh, or turn a sculpt into splats. See Gaussian splats
Generate 3DTurn an image or a description into a sculptable model. See Image and text to 3D
LOD chainA series of lighter copies of a model (LOD0, LOD1...) for game engines. See Geometry
MCPModel Context Protocol: sculptforge-cli --mcp lets AI agents such as Claude run SculptForge commands
Send to UnrealExport and import a model into a running Unreal Editor in one step (Ctrl+U)
Shelves, palettes, traysThe interface around the canvas: shelves hold the most-used controls, palettes hold everything, trays hold pinned palettes. See The interface
Studio brush folderA shared, read-only brush folder for a team (SCULPTFORGE_BRUSH_PATH). See For studios
