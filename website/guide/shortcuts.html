Keyboard and mouse

This chapter is the reference for every default keyboard shortcut and mouse gesture in SculptForge. Inside the app, F1 opens the same list as the Controls window, showing your own keys if you've changed any.

Changing shortcuts#

Every key below can be reassigned: hold Ctrl+Alt and click a button, then press the new key, or use Preferences > Hotkeys. Press Ctrl+Shift+I (Store Config) to keep your changes. See Customizing the interface.

On macOS, Cmd works wherever a shortcut says Ctrl. Single-letter shortcuts don't fire while you type in a text field.

Keyboard shortcuts#

The table lists the default shortcut of every action, grouped by palette. It is generated from SculptForge's action registry, the same source as the Controls window.

Brush#

ActionKeysWhat it does
Brush pickerBPop up every brush under the cursor. Type the first letter of a brush, then the orange letter on its tile (B S T = Standard).
Clay2Builds up clay that fills the hollows first.
ClayBuildup0Square, flat-topped clay strokes for blocking in forms.
Crease6Cuts a sharp crease; Alt raises a ridge.
DamStandard9A sharp V-shaped crease with the sides pinched in (ZBrush DamStandard).
Flatten7Presses the surface toward a plane.
Inflate5Swells the surface outward along its normals.
Move4Grabs the surface under the cursor and pulls it along.
Paste brushCtrl+VAdd the brush on the clipboard: a brush code someone shared, or the text of a .sfbrush file.
Pinch8Pulls the surface toward the stroke to tighten edges.
Smooth3Relaxes the surface. Hold Shift to smooth with any brush.
Standard1Raises the surface along the stroke; Alt digs in.

Color#

ActionKeysWhat it does
Pick colourCTake the paint colour from the model under the cursor.

Draw#

ActionKeysWhat it does
Draw Size at cursorSA Draw Size slider under the cursor: drag it, or type a number and press Enter.
Larger brush]Make the brush 10% larger (hold to repeat).
PaintPPaint colour without sculpting (ZBrush Rgb on, Zadd off). Alt paints back to white, Shift still smooths.
Smaller brush[Make the brush 10% smaller (hold to repeat).
Strength at cursorIA Strength slider under the cursor: drag it, or type a number and press Enter.

Edit#

ActionKeysWhat it does
RedoCtrl+Shift+Z or Ctrl+YRedo the last undone action.
UndoCtrl+ZUndo the last action.

File#

ActionKeysWhat it does
Export GLB...Ctrl+EExport the model as glTF binary, with sculpt layers as blend shapes (morph targets).
New SphereCtrl+NReplace the scene with a new sphere ready for sculpting.
Open...Ctrl+OOpen a project (.sfproj), a model (.obj, .glb, .fbx, .stl, .ply, .usd ...) or splats.
QuitCtrl+QClose SculptForge (asks to save changes first).
SaveCtrl+SSave the project (.sfproj: every SubTool, layer, brush and setting). Asks for a name the first time.
Save As...Ctrl+Shift+SSave the project under a new name.
Send to UnrealCtrl+UExport a game-ready FBX and import it into the running Unreal Editor (Python remote execution).

Help#

ActionKeysWhat it does
Command paletteF3 or Ctrl+Shift+PSearch every command, brush and setting by name and run it. Commands that need parameters open in the console.
ControlsF1Every shortcut and mouse gesture, generated from the commands themselves.
User GuideShift+F1The SculptForge user guide: every tool explained, with search. Hold Ctrl over a control and press F1 to open the chapter about it.

LightBox#

ActionKeysWhat it does
LightBox,Show or hide the LightBox: thumbnails of your projects, models, brushes, alphas, materials, images, splats and QuickSaves along the top of the canvas. Double-click to load.

Material#

ActionKeysWhat it does
Material pickerMPop up the materials under the cursor. Hover one to preview it on the model; click to keep it.

Preferences#

ActionKeysWhat it does
Load UI...Ctrl+LLoad a layout file someone shared (or you saved with Save UI).
ShelvesTabHide or show the shelves and trays around the canvas.
Store ConfigCtrl+Shift+IKeep the current layout, shortcuts and interface preferences for future sessions. Like ZBrush, SculptForge never saves them on its own.

Render#

ActionKeysWhat it does
FullscreenF11Fill the screen with SculptForge (again: back to a window).
WireframeW or Shift+FShow the mesh's polygons (quads and triangles) over the surface (ZBrush PolyFrame).

Script#

ActionKeysWhat it does
Console`The script console: every command you run appears as a script line, and you can type commands yourself.

Tool#

ActionKeysWhat it does
SubdivideCtrl+DSmoothly subdivide the mesh (Loop subdivision). Each level multiplies the triangle count by 4.

Transform#

ActionKeysWhat it does
FrameFFit the whole model in the view.
XXMirror strokes across X (left and right).

Keys inside pop-ups and panels#

Some keys only mean something while a pop-up or panel has the keyboard.

Brush picker (B)#

KeyAction
A letterKeep the brushes whose names start with the letters typed so far
The orange letter on a tilePick that brush (B S T = Standard)
BackspaceTake back one letter
EnterPick the first match
EscClose

Draw Size and Strength at the cursor (S, I)#

KeyAction
Digits and .Type a value
EnterApply the typed value and close
EscClose without applying a typed value

Command palette (F3)#

KeyAction
Up / Down, Page Up / Page DownChoose a row
EnterRun it
Shift+EnterOpen a command with parameters in the console to edit them
EscClose

Console (`)#

KeyAction
EnterRun the line (statements separated by ;)
TabComplete a command or parameter name; press again to list the candidates
Up / DownWalk through earlier lines (the last 200 are remembered between sessions)

Shortcut capture (Ctrl+Alt+click)#

KeyAction
Any key or chordBecomes the new shortcut (taken from another action if it had it)
Backspace or DeleteRemove the shortcut
EscCancel

ZBrush keys that work differently#

Most ZBrush shortcuts do the same thing in SculptForge. A few differ because the feature works differently or doesn't exist yet:

ZBrushSculptForge
D / Shift+D (subdivision level up / down)No subdivision levels yet; Ctrl+D subdivides once and can be undone
Space (QuickMenu)No QuickMenu; use the left-shelf tiles, B, M, S and I
O (Focal Shift)No focal shift setting
Q W E R (Draw, Move, Scale, Rotate gizmo)No transform gizmo; W toggles the wireframe (PolyF)
Ctrl+W (group masked)Tool > Polygroups > From mask
Shift (snap the view while rotating)No view snapping yet
H (hide the ZScript window)` toggles the console
